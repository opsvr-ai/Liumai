# 知识中心页面重设计

## 目标

将当前混合弹窗 + 双Tab的松散页面，重构为清晰的四Tab内联布局。

## 当前问题

- 672行单文件，功能混在一起
- 上传、命中测试、Webhook创建都用浮层弹窗
- Webhook列表埋在文档列表下方
- 2个Tab（知识管理/知识蒸馏）不够细，一个Tab内太多东西

## 目标设计

4个独立Tab，每个Tab内联所有操作（零弹窗）：

### Tab 1: 知识库
- 统计卡片: 文档总数/已存储/失败/累计命中
- 搜索 + 状态过滤
- 上传按钮（内联文本区或文件选择器，不再弹窗）
- 左右分栏: 文档列表 + 选中详情

### Tab 2: Webhook
- 统计: Webhook数/总请求/知识条数
- 新增行（内联输入 + 创建按钮）
- Webhook列表: 名称/请求次数/文档数/最近时间/复制URL/删除
- 折叠帮助面板: curl示例

### Tab 3: 命中测试
- 输入区: 问题 + 测试按钮
- 结果展示: 命中/未命中 + 回答 + 来源 + 反馈按钮
- 历史记录列表

### Tab 4: 知识蒸馏
- 统计: 候选/已批准/已拒绝/平均分/排队数
- 蒸馏按钮 + 排队计数 + 自动蒸馏开关
- 候选列表: 标题/分类/评分条/批准拒绝操作

## 关键文件

| 文件 | 改动 |
|------|------|
| `src/pages/knowledge.tsx` | 重构为四Tab布局，内联所有操作 |

## 验证

- 四个Tab各自独立切换，状态不互扰
- 上传文档无需弹窗
- Webhook创建后立即出现在列表中
- 命中测试结果带历史记录
- 蒸馏候选可批准/拒绝
